# 关键信息捕获

从当前页面抓取四类关键信息——**题目 ID、队列名称、题目链接、alloc 镜像 image**——拼成一行制表符分隔文本，方便直接粘进表格或工单系统。

> 状态：可用（v1.0.0）。标「待补充」处按实际实现补齐。

## 基本信息

| 项 | 值 |
| --- | --- |
| 扩展名称 | 关键信息捕获 |
| 版本 | 1.0.0 |
| Manifest | V3 |
| 弹窗入口 | `popup.html` + `popup.js` |
| 后台 | 无（纯 popup + content script） |
| 内容脚本 | `content.js`，`<all_urls>`，`document_idle` 注入 |
| 权限 | `activeTab`、`scripting`、`storage`、`clipboardRead`、`clipboardWrite` |

## 功能

- 一键抓取当前页面的四类字段：题目 ID、队列名称、题目链接、alloc 镜像 image。
- 按固定顺序用 **制表符（`\t`）** 拼接为一行，四列分别对应页面上四个位置。
- 抓取失败时保留空位，保证列不错位（待补充：缺失字段的占位符是什么）。
- 支持复制到剪贴板，也支持直接粘贴原文本再解析。
- 历史记录保存在本地，可回看最近若干条（待补充：保留条数）。

## 输出示例

```
<题目ID>	<队列名称>	<题目链接>	<alloc镜像image>
```

> 列顺序固定，用制表符分隔；粘到 Excel / WPS 会自动分列。

## 目录结构

```
info-capture-extension/
├── manifest.json   # 扩展声明：权限、popup、content script
├── popup.html      # 弹窗界面：抓取按钮、结果框、历史
├── popup.js        # 抓取调度、剪贴板、存储
├── content.js      # 页面内提取四类字段并回传

```

## 安装与加载

1. `chrome://extensions` → 开启「开发者模式」。
2. 「加载已解压的扩展程序」→ 选择 `info-capture-extension/`。
3. 打开目标页面，点击工具栏图标。

## 使用说明

1. 在目标页面点击扩展图标。
2. 点「抓取」，弹窗显示四列结果与拼接后的整行文本。
3. 点「复制」写入剪贴板；或手动全选复制。
4. 如需记录，点「保存」进入历史列表。

### 页面字段对应关系

| 列 | 含义 | 页面来源（待补充） |
| --- | --- | --- |
| 1 | 题目 ID | 例如详情页标题旁的数字编号 |
| 2 | 队列名称 | 例如任务列表中的队列标签 |
| 3 | 题目链接 | 当前详情页 URL |

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 点击图标后访问当前标签页 |
| `scripting` | 注入提取脚本 |
| `storage` | 保存历史与最近结果 |
| `clipboardRead` | 读取用户已有文本用于解析（如不解析可移除） |
| `clipboardWrite` | 一键复制结果 |

## 开发与调试

- 弹窗：右键图标 →「检查弹出内容」。
- 页面脚本：F12 控制台查看 `content.js` 日志。
- 抓不到字段时，先在控制台手动执行选择器，确认页面结构有没有变。
